# bam-_boo_!

**bam-_boo_!** is a full-stack application with a React and Vite frontend and a Python Django backend. Built by team **kale** for the [Focus in Technology Leadership](https://www.technologyleadershipinitiative.com/) as part of [CSC207H1](https://artsci.calendar.utoronto.ca/course/csc207h1) Fall 2026.
